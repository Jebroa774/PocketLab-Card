# Manufacturing outputs

This folder will hold only generated and reviewed release artifacts:

- Gerber and drill files
- Pick-and-place / component-position file
- Assembly BOM with supplier part numbers
- Schematic and assembly PDFs
- PCB fabrication notes and stack-up
- Antenna variant notes

The first order should be five fully assembled boards, with expansion headers
left unpopulated. RF matching values may need rework after V1 antenna tests, so
the first PCB must include accessible matching components and RF test points.
